C++ Clothing Store Management System

A console-based clothing store management system developed in C++ as a first-semester programming project.

The project simulates basic operations of a clothing store through a menu-driven console interface.

Features

- Customer interaction through a console menu
- Clothing/product selection
- Product information display
- Price calculation
- Order/purchase processing
- Basic input validation
- Menu-driven navigation

Technologies Used

- Language: C++
- Interface: Console / Command Line
- Compiler: g++ / MinGW

How to Run

Using g++

Clone the repository:

git clone https://github.com/YOUR-USERNAME/cpp-clothing-store.git

Navigate into the project:

cd cpp-clothing-store

Compile the program:

g++ src/main.cpp -o clothing-store

Run the program:

Windows

clothing-store.exe

Linux / macOS

./clothing-store
